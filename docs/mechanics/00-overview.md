# PixelKin — Mechanics & Balance (overview)

This folder is the design + data backbone for PixelKin's creatures, battles, and
collection loop: the **151 kin**, their types, stats, moves, capture, and
growth, all costed against a shared power budget and **empirically balanced** by
a Monte Carlo simulator.

It is grounded in the existing world: see `docs/world/story-bible.md` (Vesperholm,
the Lampwardens, the Hollowing) and `docs/world/atlas.md` (the 14 areas). The
copyright rules in `VISION.md` are non-negotiable — everything here is original.

## Key decisions (all changeable later; rationale in each doc)

| Thing | Decision | Why |
|-------|----------|-----|
| Creatures | **kin** | already canon in the repo |
| Capture device | **Lamps** (Spark/Glow/Beacon/Starlamp + specialty) | fits the lamp-tender hero; inverse of the villains' null-lanterns (`04`) |
| Evolution | **Kindling** (a kin *kindles*) | ties to "kin" + the game's core act of relighting constellations (`05`) |
| Types | the **10** from the story bible (8 constellations + Light/Dark) | lore-locked; leaner than 18, enriched by dual-typing (`01`) |
| Stats | the genre's **six** (hp/atk/def/spa/spd/spe) | readable; matches the two existing sample kin (`02`) |
| Moves | **≤4 per kin**, ~94-move shared pool + signatures | classic feel, coverage-complete (`03`) |
| Roster build | overshoot to **~500 concepts → curate to 151** | every dex slot is a contest winner; leaves an idea bank (`07`) |

## Read in order

1. `01-type-system.md` — the 10 types + the tuned effectiveness chart.
2. `02-stats-and-balance.md` — six stats, BST tiers, role templates, the power
   budget (EPS), and the damage formula.
3. `03-moves.md` — move/ability data shape, power bands, status conditions,
   learnsets, the 4-move rule.
4. `04-capture.md` — the Lamp system + catch maths.
5. `05-kindling.md` — the evolution (kindling) system + triggers.
6. `06-progression-and-distribution.md` — biome→type→level→rarity map, the
   "awe curve," starters, legendaries.
7. `07-selection-process.md` — the 500→151 panel-scored, distribution-
   constrained pipeline.
8. `08-data-schema.md` — the concept and species JSON contracts.
9. `09-simulator.md` — how the balance tooling works and how to run it.

## Data & tools

- `src/game/data/type-chart.json` — authoritative type chart.
- `src/game/data/moves.json` — authoritative moves + abilities (generated by
  `tools/balance/gen_moves.py`).
- `src/game/data/species/NNN_slug.json` — the final 151 (one file each).
- `tools/balance/` — the JS balance engine:
  - `chart_check.mjs` — validates the type chart on a synthetic fair roster.
  - `validate.mjs` — schema + power-budget + whole-line checks on the roster.
  - `simulate.mjs` — full-roster Monte Carlo, win-rate & outlier report.
  - `select.mjs` — distribution-constrained 500→151 picker.
- `docs/mechanics/concepts/pool/` — the ~500 brainstormed concepts.
- `docs/mechanics/concepts/archive/` — the cut concepts (kept as an idea bank).
