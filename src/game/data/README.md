# Data

Data-driven game definitions live here as typed TypeScript (or imported JSON):
creature species, move/ability lists, elemental type chart, encounter tables,
items, and dialogue.

Keeping the game **data-driven** is deliberate — content (a new creature, a new
move) should be a data edit, not a code change. It also keeps a clean line
between original PixelKin content and anything resembling another franchise's
data, which matters for the copyright posture in `../../../VISION.md`.
